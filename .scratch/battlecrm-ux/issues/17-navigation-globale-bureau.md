# Navigation globale (bureau)

Type: prototype
Status: open
Blocked by: 12, 13, 14, 15

## Question

Quelle est la structure de navigation sur bureau : entrées du menu latéral, place et contenu de la palette de commandes (`Ctrl K`), ajout rapide (`N`), et raccourcis globaux ?

Déjà tranché : « Aujourd'hui » est l'écran d'arrivée ; « Battles » est un écran à deux onglets (Battles, Historique des Champions) ; « Indicateurs » a sa propre entrée. Le mobile est tranché (onglets Aujourd'hui, Contacts, Funnel, Plus ; bouton + ; loupe comme palette, voir le ticket « Parcours mobile ») : la navigation bureau doit rester cohérente avec lui. Le reste dépend de l'inventaire des écrans (fiche Contact, Positionnements, Réglages, Organisations).
